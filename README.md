# Reels Montage Guide

Гайд и рендер-движок для сборки коротких вертикальных роликов (9:16, «говорящая голова» +
чёрная рамка + карточка + вставки + синие числа) с помощью Claude Code. Стиль — фирменный:
геометрия карточек, палитра, типографика субтитров, ритм монтажа и звук зафиксированы и
измерены по эталонным роликам (см. `exemplars.md`). Claude монтирует по этим правилам сам,
без «на глаз».

Это не готовое приложение — это **гайд + библиотека Python-скриптов**, которые Claude Code
читает и запускает у тебя на компьютере через терминал (ffmpeg, Python, whisper).

## Что нужно поставить заранее

1. **Python 3.10+** и зависимости:
   ```bash
   pip install -r requirements.txt
   ```
   (numpy, opencv-python, Pillow — на них держится весь рендер: маски карточек, текст, кадры)

2. **ffmpeg** — вся склейка, кроп, грейд и мукс звука идут через него:
   ```bash
   brew install ffmpeg                        # macOS
   sudo apt install ffmpeg                    # Linux (Debian/Ubuntu)
   sudo dnf install ffmpeg                    # Linux (Fedora)
   winget install Gyan.FFmpeg                 # Windows (или choco install ffmpeg)
   ```
   На Windows после установки через `winget`/`choco` проверь, что `ffmpeg` виден в PATH
   (`ffmpeg -version` в новом окне терминала).

3. **Транскрипция — нужен ключ OpenAI (Whisper API).** Пословные тайминги — основа и
   субтитров, и резов по картинке; Claude дёргает API сам через `curl`, ничего вручную
   запускать не нужно, транскрипция занимает секунды, а не минуты ожидания на CPU.
   Ключ — на [platform.openai.com/api-keys](https://platform.openai.com/api-keys) (нужен
   привязанный способ оплаты, но сама транскрипция стоит копейки: ~$0.006/минуту звука);
   куда его положить — см. пункт 4.

   **Без ключа** — запасной вариант, локальный `whisper` (медленнее, минуты на CPU за
   короткий ролик, но бесплатно и без сети):
   ```bash
   pip install openai-whisper
   ```
   Для ускорения локального варианта лучше сразу поставить **faster-whisper** или
   **whisper.cpp** (с Metal-ускорением на Mac) — та же точность, в разы быстрее обычного
   `openai-whisper` на CPU.

4. **Ключи API для стокового видео и транскрипции** — без них Claude почти ничего не
   сможет найти и распознать сам:
   - [OpenAI](https://platform.openai.com/api-keys) — транскрипция (см. пункт 3).
   - [Pexels API](https://www.pexels.com/api/) — бесплатный ключ, регистрация за 2 минуты.
   - [Pixabay API](https://pixabay.com/api/docs/) — бесплатный ключ, тоже 2 минуты
     (ключ показывается на странице документации, когда ты залогинен).

   Все ключи положи в `build/.env` (создай файл сам, его нет в репозитории — см. ниже):
   ```
   OPENAI_API_KEY=...
   PEXELS_API_KEY=...
   PIXABAY_API_KEY=...
   ```
   Этот файл в `.gitignore` — никогда не коммить и не отправляй ключи в чат публично.

5. **Шрифты** — по умолчанию используются системные шрифты macOS (`style.py`, пути
   `/System/Library/Fonts/...`). На Linux/Windows их нет — придётся подставить свои пути в
   `build/style.py` (нужны: гротеск, его курсив, высококонтрастный serif italic — см.
   `brand-kit.md §3`).

6. **Claude Code** (или другая среда, где Claude может выполнять код в терминале) — без
   выполнения кода Claude не сможет прогнать ffmpeg/whisper/рендер.

## Установка

```bash
git clone https://github.com/VladimirKalajcidi/reels-montage-guide.git
cd reels-montage-guide
pip install -r requirements.txt
```

Создай `build/.env` с ключами (см. пункт 4 выше).

## Куда класть исходники

- **Видео**: `videos/<номер>/source.mov` — один готовый чистый дубль на один ролик
  (без пауз, повторов и фальстартов — речь потом не режется). Номер — просто следующий
  свободный (1, 2, 3, ...).
- **Музыка** (необязательно): `.mp3`-файлы в `audios/` — своя или лицензированная. Подложится
  автоматически, если ты укажешь трек в `sfx<N>.py`.

Готовый ролик появится рядом с исходником: `videos/<номер>/<тег>_edit.mp4`.

## Как запускать — какой промпт дать Claude

Самый простой способ — открыть новый чат в Claude Code внутри этой папки, положить исходник в
`videos/<номер>/source.mov` и отправить первым сообщением текст из **`LOAD-ME.md`** (там уже
готовый шаблон, просто скопируй блок между линиями). Коротко, что он говорит Claude:

> Прочитай весь гайд, начиная с `START-HERE.md`. Ничего не спрашивай — стиль, палитра, шрифты,
> геометрия уже зафиксированы в файлах. Разбери исходник по протоколу «При получении сырого
> исходника» из `START-HERE.md`: расшифровка → раскадровка → материалы → сборка. Покажи
> монтажный план (раскадровку и список вставок) до рендера — после моего «ок» собери готовый
> mp4 и прогони обе автопроверки.

Дальше Claude сам:
1. Прогонит `ffprobe` по исходнику и расшифрует речь через OpenAI Whisper API (или локальный
   `whisper`, если ключа нет) — с пословными таймингами.
2. Разложит речь на биты и подберёт рецепт плана под каждый (`shot-recipes.md`).
3. Найдёт вставки через Pexels/Pixabay API (или Mixkit как запасной вариант) — см.
   `assets-manifest.md §3`.
4. Покажет монтажный план на согласование.
5. После твоего «ок» — соберёт `render<N>.py` + `sfx<N>.py` (копии шаблонов из `build/`,
   см. ниже), прогонит автопроверки текста и вернёт готовый `.mp4`.

### Если начинаешь новый ролик

`build/style.py`, `graph.py` (если используешь свою графику), `render.py`, `sfx.py`, `plan.py` —
это шаблоны движка, переиспользуются без изменений в логике. Для каждого нового ролика
копируются в `storyboard<N>.py` / `render<N>.py` / `sfx<N>.py` / `plan<N>.py` (число — номер
папки в `videos/`) и правится под конкретное содержание — так уже собранный ролик всегда можно
пересобрать или доработать, не реверс-инжиниря чужой рендер (см. `anti-patterns.md`).

### Если стиль ролика должен быть другим

Весь гайд настроен под конкретную визуальную идентичность (чёрная рамка, синие числа, кегли
32-200px и т.д.) — это тема репетиторства по математике, но сама механика (карточки, рецепты
планов, субтитры-блоки) не привязана к теме. Если нужен другой стиль или тема — начни с
`brand-kit.md §1` (Идентичность) и `shot-recipes.md` (набор рецептов), остальное подстроится.

## Структура репозитория

| путь | что внутри |
|---|---|
| `LOAD-ME.md` | готовое первое сообщение для Claude |
| `START-HERE.md` | протокол работы (блоки, `status.md`, что не спрашивать) |
| `brand-kit.md` | холст, карточки, палитра, шрифты, субтитры |
| `shot-recipes.md` | рецепты планов (R1–R11) |
| `editing-taste.md` | нарратив, ритм, склейки |
| `delivery-specs.md` | формат, звук, QA-чеклист |
| `anti-patterns.md` | «так не делать» — по реальным разборам |
| `assets-manifest.md` | источники стока (Pexels/Pixabay/Mixkit), шрифты, звук |
| `exemplars.md` | разбор эталонных роликов (сами видео не включены — см. файл) |
| `build/*.py` | движок рендера — шаблоны, см. выше |
| `videos/`, `audios/` | пустые — твои исходники сюда, в репозиторий не попадают (`.gitignore`) |

## Известные ограничения

- Проверено и настроено под **macOS** (шрифты, `ffmpeg` через Homebrew). На Linux/Windows
  потребуется адаптация путей к шрифтам.
- Whisper на CPU — медленно (десятки минут на минуту речи на слабом железе). См. пункт 3 выше
  про faster-whisper/whisper.cpp.
- Геометрия кропа лица (`FRAMINGS` в `render<N>.py`) подбирается вручную под конкретный
  дубль — единой формулы нет, Claude подбирает по кадру перед полным рендером.

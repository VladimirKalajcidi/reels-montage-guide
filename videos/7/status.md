## Ручная проверка (контакт-лист)
- Все сток-вставки семантически соответствуют произносимому (дата-центр/инженеры,
  приборная панель авто, стопка резюме, собеседование, пешеходный переход, объектив камеры,
  блик солнца, техник с кабелями, книги — «готовая библиотека», доска с формулами
  вероятностей, класс с векторами/координатами, девочка у школы — «закладывается в детстве»).
- Оба числа-ревила («1 000 000 ₽ в месяц», «0,01 с на решение») влезают в карточку с запасом,
  свечение и позиция подписи корректны.
- **Найдена и исправлена подмена стокового файла**: клип Mixkit 5886 («girl-walking-to-school»)
  на `-1080.mp4` отдавал случайный посторонний ролик (капля мёда на решётке, 12с) вместо
  заявленных 21с с девочкой у школы — битые данные на CDN Mixkit, не ошибка скачивания.
  Обнаружено только по контакт-листу (глазами), автопроверки текста/графики это не ловят.
  Исправлено перекачкой `-720.mp4` (верный ролик, 20.75с). Урок записан в
  `assets-manifest.md §2` — впредь сверять длительность файла с длительностью на странице.

## Продолжить в новой сессии
Пересобрать состояние (если нужно):
```
cd build && python3 render41.py && python3 sfx41.py
ffmpeg -y -i ../videos/7/cv_engineer_edit.mp4 -c:v copy \
  -af "volume=0.35dB,alimiter=limit=0.80:level=disabled" -c:a aac -b:a 192k /tmp/v7.mp4 \
  && mv /tmp/v7.mp4 ../videos/7/cv_engineer_edit.mp4
```
Громкость: однопроходный `loudnorm` дал -14.7 LUFS / -1.3 dBTP (недобор ~0.7dB, как в
роликах 3/4/5). Исправлено доп. проходом `volume=0.35dB,alimiter=limit=0.80` →
**-14.5 LUFS, -1.7 dBTP**. Вариант `volume=0.5dB,limit=0.82` тоже пробовался — дал
переусиленный истинный пик (межсэмпловый овершут, ffprobe/loudnorm показали >0dBTP),
отклонён по правилу delivery-specs.md («если итерация ловит и громкость, и пик — не
отдавать, вернуть предыдущую, которая прошла по пику»).
Гайд заново не перечитывать — качество уже проверено, QA по нулям.

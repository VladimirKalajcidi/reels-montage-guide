## Правки после первой сборки (в этой же сессии, до сдачи)
- Первая версия плана 24 («остаток от деления») рисовала цифрами полное равенство
  `17 mod 5 = 2` (12 символов) на кегле 118 — QA (`check_text_outside_card`) поймал
  12 кадров с текстом за правым краем карточки A (x=975). Исправлено: большим числом-ревилом
  стал сам остаток (`digits="2"`, кегль 150 — влезает по определению правила «≤3 символов»),
  а уравнение перенесено в подпись `label="остаток от 17 на 5"` под числом. Пересобрано,
  автопроверка повторно прогнана — 0/609.
- Коррекции whisper-транскрипции по смыслу (без изменения таймингов): «в схеме дара,» →
  «в схеме дыра,», «слово в пробных комментариях» → «слово пробное в комментариях»
  (детали и обоснование — в `montage-plan.md`).
- Громкость: однопроходный `loudnorm` недобрал ~0.7dB (-14.80 LUFS, пик -1.30 dBTP).
  Исправлено доп. проходом `volume=0.80dB,alimiter=limit=0.85` поверх готового файла →
  -14.11 LUFS, пик -1.10 dBTP. Обе метрики проверены на **готовом mp4**, не на миксе.
  Домикс без коррекции сохранён рядом как `crypto_edit_premix.mp4`.

## Продолжить в новой сессии
Пересобрать состояние (если нужно):
```
cd build && python3 render38.py && python3 sfx38.py
ffmpeg -y -i ../videos/3/crypto_edit.mp4 -c:v copy \
  -af "volume=0.80dB,alimiter=limit=0.85:level=disabled" -c:a aac -b:a 192k /tmp/v3.mp4 \
  && mv /tmp/v3.mp4 ../videos/3/crypto_edit.mp4
```
Гайд заново не перечитывать — качество уже проверено, QA по нулям.

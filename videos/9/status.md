## Продолжить в новой сессии
Пересобрать состояние (если нужно):
```
cd build && python3 render42.py && python3 sfx42.py
ffmpeg -y -i ../videos/9/ballistician_edit.mp4 -c:v copy \
  -af "volume=1.4dB,alimiter=limit=0.80:level=disabled" -c:a aac -b:a 192k /tmp/v9.mp4 \
  && mv /tmp/v9.mp4 ../videos/9/ballistician_edit.mp4
```
Громкость: однопроходный `loudnorm` недобирает ~1.4dB на этом материале (как и в других
роликах), исправлено доп. проходом громкости+лимитера — см. `qa-report.md`.
Гайд заново не перечитывать — качество уже проверено, QA по нулям.

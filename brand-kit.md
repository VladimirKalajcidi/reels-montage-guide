# Brand Kit — визуальная система (единый источник правды)

Всё оформление сверяется с этим файлом. Не дублируй палитру / шрифты / геометрию в других местах —
правь только здесь. Числа измерены с эталонных роликов и приведены к холсту **1080×1920**.

## 1. Идентичность
- Кто в кадре: **я** — говорящая голова, дневной свет, домашний/учебный интерьер,
  петличка в руке. Кадр спокойный, статичный, без движения камеры.
- Тема: **репетиторство по математике + интересные факты о математике**. Один ролик = один факт,
  один парадокс, одна задача или одна прикладная идея. Никакого «10 лайфхаков».
- Формат: вертикаль 1080×1920.
- Тон: **спокойно, уверенно, без крика и без «вау-энергии».** Ровный голос, короткие фразы,
  разговорный синтаксис. Интрига строится текстом и монтажом, а не подачей.

> Имя, название канала, хэндлы площадок, портрет аудитории, точная формулировка CTA —
> **не спрашивать**. Для монтажа это не нужно, на кадре ничего из этого не появляется.

### Обработка исходника (делается всегда, без вопросов)
- **Отзеркалить по горизонтали**, если снято на фронтальную камеру: надписи на одежде и в интерьере
  иначе читаются задом наперёд.
- **Грейд**: поднять гамму, слегка подогреть, чуть добавить контраста и резкости.
  Рабочая связка: `eq=gamma=1.18:contrast=1.06:saturation=1.10:brightness=0.02`,
  `colorbalance=rm=0.04:gm=0.008:bm=-0.03`, `unsharp=5:5:0.30`.
  Цель — тёплый живой кадр вместо серого плоского исходника.

## 2. Холст и рамка — главный признак стиля
Ролик **не занимает весь экран**. Кадр — это чёрное полотно, на котором лежит карточка со скруглёнными углами.
Чёрные поля вокруг карточки — не баг, это и есть рамка.

- Холст: **1080×1920**, фон — **чистый #000000** (не тёмно-серый, не градиент).
- Всё содержимое живёт в одной из двух карточек. Обе имеют **общий центр (540, 925)** —
  50% по ширине, 48% по высоте. При смене типа карточки центр не прыгает.

### Карточка A — говорящая голова (вертикальная)
| параметр | значение |
|---|---|
| позиция | x **105**, y **238** |
| размер | **870 × 1380** (правый край 975, нижний 1618) |
| поля | слева/справа **105px** (9.7%), сверху **238px**, снизу **303px** |
| соотношение | ≈ **1 : 1.585** |
| радиус скругления | **60px** |

### Карточка B — вставка (горизонтальная)
| параметр | значение |
|---|---|
| позиция | x **110**, y **614** |
| размер | **858 × 620** (правый край 968, нижний 1234) |
| соотношение | ≈ **1.385 : 1** (между 4:3 и 3:2 — не 16:9!) |
| радиус скругления | **50px** |

Кино-кадр 16:9 **обрезается по бокам** до 1.385:1, а не вписывается с полями. Композицию клипа
кадрируем сами — важный объект держим в центре.

### Правила рамки
- Карточка **не двигается и не масштабируется внутри плана**. Ни зума, ни Ken Burns, ни дрейфа.
  Крупность меняется только сменой дубля или сменой типа карточки.
- Смена карточки — **всегда прямой рез, один кадр**. Никаких кроссфейдов между карточками.
- **Текст никогда не выходит за границы карточки.** Отступ ≥30px внутрь от её краёв (см. §5).

## 3. Типографика
Два шрифта, три начертания. Больше — нельзя.

### Основной: геометрический гротеск
Опознавательные признаки эталона: **одноэтажная «а»** (круг + прямая стойка), круглая «о»,
высокая x-height, монолинейный штрих, «9» = круг с прямым хвостом, «1» с маленьким флажком.
Начертания: Regular/Medium + **Italic** (наклонное того же гротеска).

**Основной шрифт проекта: Onest** (запаска — **Golos Text**). Оба бесплатные, с полной кириллицей,
открытая лицензия. Ближе всего к эталону геометрически стоит платный Gilroy — но разница видна
только при прямом наложении, и на реальном кадре не читается.

Точное имя шрифта в эталоне **не подтверждено** — совпадать должны признаки начертания выше,
а не название.

### Акцентный: высококонтрастный serif italic
Тонкие соединительные, каплевидные окончания, курсивные строчные. Кандидат: **Playfair Display Italic**
(есть кириллица). Запаска: PT Serif Italic, Bodoni.

Используется **только для «смысловых» слов** — терминов, понятий, вердиктов:
*вероятность*, *почти нет*, *против*, *в среднем*, *невозможно*, *гарантия*.
Никогда — для чисел и никогда — для целой фразы длиннее 3 слов.

### Шкала кеглей (1080×1920)
| уровень | кегль | для чего |
|---|---|---|
| **XS** | 32–40px | служебные связки: «что», «например», «идёшь» |
| **S** | 45–60px | основной поток речи — 80% всех субтитров |
| **M** | 70–90px | акцент фразы, подпись-заголовок над вставкой |
| **L** | 110–140px | ключевой термин, крупное слово в карточке (R6) |
| **XL** | 150–200px | число-ревил, главное слово ролика |

Разброс кеглей внутри одного ролика **обязателен** — от 32 до 200px. Один кегль на всё = мёртвый ролик.

## 4. Палитра
| роль | цвет | где |
|---|---|---|
| фон | **#000000** | полотно вокруг карточки |
| текст | **#FFFFFF** | подавляющее большинство текста |
| **акцент** | **#3B4BE8** (рабочий диапазон #2E3EC8 … #5B7CFF) | **числа и результаты**, изредка — одно слово-вердикт |
| свечение акцента | **#6B87F9** | внешний glow под синим текстом |
| второй акцент | #C3DB4E (кислотный лайм) | **только внутри инфографики**, максимум один элемент на ролик |

Правила:
- Синий — это **цвет числа**. Проценты, количества, результаты вычислений. Не раскрашивай им обычные слова.
- Белый текст поверх видео — **мягкое внешнее свечение** (белое, радиус ~12–16px, ~40%), без жёсткой обводки
  и без плашек-подложек.
- Синий текст — **свечение того же оттенка**, радиус ~30–40px, заметное. Число должно «гореть».
- Никакой радуги. Кроме белого и синего в кадре не должно быть ни одного собственного цвета —
  всё остальное приходит из видео-вставок.

## 5. Субтитры — вторая главная примета стиля
Субтитры здесь **не подпись под видео, а графика в кадре**. Они разбросаны, разного размера, разного начертания.

### Текст
- **Строчные буквы. Без КАПСА** (капс — только для крупного слова в карточке, рецепт R6).
- **Без пунктуации.** Убирать `. , ! ? « » : ; —`. Тире допустимо, если оно несёт смысл («а не в этой раздаче»).
- **2–4 слова на фразу.** Одна фраза = один вдох.
- Внутри одной фразы можно смешивать начертания: `практически` (прямой) + *`гарантия`* (курсив).

### Раскладка блоками
Фразы **не сменяют друг друга по одной** — они копятся. Это главный механизм.

**Блок = 2–3 фразы, которые висят на экране одновременно.** Блок обрывается и очищается целиком,
когда: сменился план, в речи пауза >0.30с, или в блоке уже 3 фразы.

Внутри блока:
- новая фраза появляется **рядом с предыдущей, а не вместо неё**;
- **старые приглушаются**: свежая 100% → предыдущая 74% → самая старая 58%;
- кегль слегка гуляет: вторая строка +8%, третья −6% (не больше — иначе каша).

**Два режима раскладки, чередуются:**

| режим | когда | как |
|---|---|---|
| **разброс** | 2 блока из 3 | строки смещаются по горизонтали в пределах **±58px** и стоят на своих уровнях |
| **спокойный** | **каждый третий блок** | ровная колонка по центру, без смещений и без игры кеглем |

Чередование обязательно. Разброс на каждом блоке подряд выглядит дёргано — ролик перестаёт читаться.

**Базовые точки:**
| ситуация | точка |
|---|---|
| поверх лица | центр X 540, базовая линия **y 1305** (под подбородком, поверх груди/рук) |
| поверх графики на сетке | **левым флагом** от x 167, первая строка y 372 |
| поверх стоковой вставки | **левым флагом** от x 136, первая строка y 706 (внутри карточки B) |
| привязка к конкретному элементу (число, схема) | своя точка, задаётся в раскадровке |

### Текст и графика: разные зоны кадра — жёсткое правило
**Субтитр и графический элемент никогда не занимают одно и то же место.** Кривые, окружности,
оси, крупные глифы, схемы не должны заходить на текст ни на пиксель. Это ловится машинно, не глазами.

Сетка-подложка (R4) — исключение: она фон, текст поверх неё лежит по определению.
Правило касается **элементов переднего плана**: линий, фигур, символов, чисел.

| зона на плане с графикой (вертикальная сетка, габарит карточки A) | границы |
|---|---|
| **зона субтитров** | y **300…600**, левым флагом от x 167 |
| разделительный зазор | y 600…700 — пустой, под свечение |
| **зона графики** | y **700…1560**, x 175…905 |

- Графика **не поднимается выше y 700**. Субтитр **не опускается ниже y 600**.
- На плане с лицом (R1) графики нет вообще — субтитр живёт на своей базовой линии y 1305.
- На стоковой вставке (R2) графики нет — субтитр внутри карточки B от x 136, y 706.
- Проверять **пиксельно**: слой графики и слой текста не должны иметь ни одного общего пикселя
  (порог альфы 40). Ожидаемый результат — ноль.

### Одно и то же не пишется дважды
**Если графика уже показывает слово, формулу или число — субтитр это не повторяет.**
Дублирование смысла в двух местах одного кадра выглядит грубо и съедает кадр.

| в речи звучит | на экране |
|---|---|
| «e в степени i умноженное на pi плюс 1 равно 0» | **только графика формулы**, субтитров нет |
| «это 0 и 1» | **только графика** с 0 и 1, субтитра нет |
| «отношение длины окружности к диаметру» | субтитр несёт слова, графика — **без подписей**, только круг и развёртка |
| «мира роста изменений» | субтитр несёт слова, у кривой **нет подписи «рост»** |

Как решать: **сначала выбрать носителя смысла** — либо графика, либо субтитр, но не оба.
Подпись на графике допустима только если она **добавляет то, чего нет в речи**
(«≈ 3,14», «формула эйлера» — если это не произносится вслух).
Если на плане говорят ровно то, что нарисовано, — **субтитр на этом плане не ставится**,
и это не «мёртвый воздух»: графика в этот момент анимируется и держит кадр.

### Границы и интервалы — жёсткие правила
1. **Текст обязан целиком лежать внутри карточки.** Не внутри кадра — внутри **карточки**
   (A: 105…975 / 238…1618, B: 110…968 / 614…1234), с отступом **30px** от её краёв.
   Порядок подгонки: сначала строку **двигают**, и только если всё равно не влезает — **ужимают кегль**.
2. **Межстрочный шаг — 62px базово**, но он **считается от кегля соседних строк**:
   `шаг = max(60, (кегль_предыдущей + кегль_текущей) × 0.70)`.
   Фиксированный шаг ломается, как только в блоке появляется строка 90pt+.
3. **Если блок не влезает по высоте — двигать блок ЦЕЛИКОМ**, сохраняя интервалы.
   Прижимать вверх отдельную строку нельзя: она сядет на соседнюю.
4. **Строки внутри блока не пересекаются.** Проверять по реальным габаритам глифов, не по кеглю.

### Анимация появления
Замерено покадрово. Появление всегда состоит из **двух слоёв одновременно**:

**Слой 1 — рампа непрозрачности (обязательно, во всех случаях).**
Прозрачность **~35% → 100% за 0.35–0.45с**, `ease-out`. Именно она даёт «мягкий» вход,
даже когда сама фраза уже целиком на месте.

**Слой 2 — способ раскрытия. Выбери один вариант на весь ролик:**

| вариант | как | замер |
|---|---|---|
| **A. Печатная машинка** (эталон 1) — по умолчанию для потока речи | фраза заранее свёрстана и отцентрована, левый край зафиксирован; символы проявляются слева направо | **≈30 мс на символ** (≈33 симв/с), вся фраза за **0.35–0.6с**, синхронно речи |
| **B. Scale-in из центра** (эталон 2) — для коротких акцентных фраз | масштаб **0.5 → 1.0** из центра фразы, микро-оверщут ~3% | **8–10 кадров (≈0.30с)**, `ease-out` |

### Цикл фразы
`появление 0.3–0.45с` → `держится, пока идёт блок` → **весь блок исчезает за один кадр, без затухания**.

Фраза живёт до конца своего блока, а не до следующей фразы. Полный цикл фразы — **0.8–1.3с**,
на 70-секундный ролик получается ~75–80 фраз и ~40 блоков.

Важно: **паузы без текста нет** — блок срезается мгновенно, и следующий уже начинает
свою рампу. Именно этот контраст (резкий срез + мягкий вход) и читается как «дорого».

## 6. Свечения и обработка
- Все текстовые слои — с внешним свечением. Без него текст «отклеивается» от кадра.
- Вставки **притемняются на 25–30%** по экспозиции, чтобы белый текст поверх читался.
- Кадр с лицом — **тёплый, естественный** (R > G > B, примерно 130 / 112 / 104 по средним),
  тени приподняты (чёрная точка ~10, не 0), света не пережжены. Никакого контрастного «кино-лука» на лице.
- Зерно/шум не добавляем.

## 7. Уровень «никогда»
- Не растягивать видео на весь холст — чёрная рамка обязательна.
- Не двигать и не зумить карточку внутри плана.
- Не ставить субтитры КАПСОМ (кроме крупного слова в карточке, R6).
- Не выпускать текст за границы карточки.
- Не давать строкам блока налезать друг на друга.
- Не ставить плашки-подложки под текст.
- Не вводить третий цвет.
- Не ставить пунктуацию в субтитрах.
- Не смешивать больше двух шрифтовых семейств.
